AI-Visuals Project

This is a Python web app for creating visuals with AI.
Visual interface is elegant and minimalistic.
Machine Learning modules are done with Python but web app can use any framework and language.

Module 1: Live video instance segmentation (Using Ultralytics Yolo models)
The first module will allow the users to connect the camera of the device and implement a semantic segmentation of live video.
The number of colors and colors of the instance segmentation can be selected by the user.
The flashing efects of the colors in the video can be adjusted by the user.
The user can also select a logo image and position to display in the image.
The video can be shown full screen.
